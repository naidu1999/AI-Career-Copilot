# Release notes — v0.4.0

- Organized nine-screen workflow and responsive Indian ink themed dashboard.
- Lightweight MotionSites-inspired gradient spotlight, staggered card entrance, and
  hover motion with reduced-motion accessibility support.
- Expanded career profile, evidence filters/bulk controls/history, and reviewed status.
- Nine job providers, source catalogue, runtime ATS detection, source health, manual
  import, daily 08:00 scan, 48-hour freshness controls, and in-app notifications.
- Matching Engine v3 with eligibility blockers, six score components, required versus
  preferred skills, missing qualifications, and Qualified/Review/Ineligible states.
- Match Inbox, Shortlist, Application Studio, cover letter/interview preparation,
  expanded pipeline, archive, recruiter/follow-up/interview fields, and insights.
- Security headers, local backup, JSON export, idempotent SQLite migrations, and tests.
- Evidence changes return immediately while match recalculation runs as a background
  task; bulk review now triggers only one recalculation.

Not included: automated applications, restricted scraping, OCR, hosted multi-user auth,
or automatic inactivity deletion.

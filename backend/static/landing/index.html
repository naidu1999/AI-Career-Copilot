    FAQ

    Questions, answered.

    Does Karna OS apply to jobs for me?

    No — deliberately. Karna discovers permitted job metadata, matches and prepares documents, then opens the official portal so you submit. Automatic submission is disabled by design, which keeps your accounts safe and every application intentional.

    What is “explainable” matching?

    Matching Engine v4 runs deterministic, auditable rules — job family, title, seniority, experience, location, work authorization, sponsorship and mandatory skills. Each match shows which checks passed or failed, so a 72% is never a mystery number.

    Where does my resume and data go?

    In personal mode everything stays in a local SQLite database on your computer. Cloud AI receives content only when you trigger an AI feature and have configured that provider. Verified backups and full JSON export are built in.

    Which job boards are supported?

    Nine documented sources: Greenhouse, Lever, Ashby, SmartRecruiters, Recruitee and Arbeitnow need no key; Adzuna and Jooble use your own free credentials; USAJOBS is optional. Only documented JSON endpoints are used — no scraping.

    Do I need to pay for AI?

    No. The default is free-first: run Ollama locally, or add your own free-tier keys. Paid providers stay disabled unless you explicitly allow them per task in the AI Continuity Router.

    Will this get my profiles flagged?

    Karna never automates the portals themselves — it reads public, documented endpoints and hands you the official link. From the portal's point of view, you are just a person applying.

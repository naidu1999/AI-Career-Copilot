# Limitations

- Matching v4 is an inspectable heuristic, not a hiring probability or legal eligibility decision.
- Job descriptions can omit or misstate location, sponsorship, experience and required skills.
- Official APIs and free tiers can throttle, change or disappear.
- AI fallback models vary in quality and may produce different wording.
- ChatGPT Plus does not include OpenAI API usage.
- Ollama reliability is local but speed depends on hardware and model size.
- Cloud failover preserves a portable mirror; it does not replicate Supabase Auth or Storage.
- OCR, restricted HTML scraping, CAPTCHA automation and automatic application submission are excluded.
- In-app inactivity warnings are ineffective if a hosted user never returns; production operators
  should add a separately consented email service before enabling automated deletion.
- Templates for privacy and terms require jurisdiction-specific legal review before public launch.
- A completely free stack cannot guarantee zero downtime, indefinite retention or fixed quotas.
